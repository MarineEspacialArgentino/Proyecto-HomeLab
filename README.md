# IT Support & Infrastructure Homelab

Laboratorio práctico de soporte técnico e infraestructura IT, desarrollado para simular un entorno corporativo y documentar la resolución de incidentes frecuentes de usuarios.

El proyecto incluye configuración de servicios, diagnóstico de problemas, administración de usuarios y gestión de tickets.

## Tecnologías utilizadas

- **Sistemas operativos:** Windows 11 y Windows Server 2022.
- **Virtualización:** VMware Workstation Pro.
- **Administración:** Active Directory, DNS y permisos de red.
- **Microsoft 365:** Outlook Web y OneDrive.
- **Gestión de incidentes:** Jira.

## Entorno de laboratorio

Se implementó una infraestructura virtual compuesta por:

- Windows Server 2022 como controlador de dominio, con Active Directory y DNS.
- Windows 11 como equipo cliente unido al dominio.
- Redes virtuales NAT y Host-Only para conectividad y comunicación entre equipos.

## Metodología de resolución

Los incidentes se documentan siguiendo un procedimiento estructurado:

1. **Identificación:** descripción del problema reportado.
2. **Diagnóstico:** análisis de síntomas e identificación de la causa.
3. **Resolución:** aplicación de las acciones correctivas.
4. **Validación:** comprobación del funcionamiento.
5. **Documentación:** registro del procedimiento y evidencias.

## Objetivo

Desarrollar y demostrar competencias prácticas aplicables a puestos de **Help Desk / Service Desk N1, Soporte Técnico Junior, Gestión de Accesos (IAM) y Soporte de Infraestructura IT**.
